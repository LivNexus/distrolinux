## Conceitos Importantes
**Kernel:** O kernel é o nucleo central do sistema operacional. Ele atua como uma ponte fundamental entre o hardware do computador e os softwares. 
Ele é resposnsavél por gerenciar a memória (RAM), o processamento da CPU, gerenciar processos, controlar hardware, sistema de arquivos, rede e drivers.
**Bios:** é o "software" fundamental gravado em um chip da placa-mãe. Ela é a primeira coisa que é executada quando você liga o computador,
preparando o hardware para que o sistema operacional possa funcionar.
**Boot:** é o processo de inicialização do computador. Ele testa os componentes fisicos (Memoria RAM, disco rigido, processador, etc) e em seguida localiza o sistema operacinal no 
disco de armazenamento do computador.
**Firmware:** é um tipo de software de baixo nível gravado diretamente no hardware de um dispositivo eletrônico. Ele contem as instruções
básicas necessárias para que o equipamento inicialize, reconheça seus próprios componentes e funcione corretamente. Exemplos: BIOS.
**Grub:** é o gerenciador de inicialização padrão da maioria das distribuições Linux. Ele é o primeiro programa executado após o computador ser ligado e o sistema verificar o hardware (BIOS/UEFI),
servindo como uma ponte para carregar o sistema operacional escolhido. O GNU GRUB (GRand Unified Bootloader) é o gerenciador de inicialização padrão da maioria das distribuições Linux.
**Firewall:** é um sistema de segurança que monitora e filtra o tráfego de rede. Ele funciona como uma barreira entre uma rede confiável e uma não confiável (como a internet),
bloqueando acessos maliciosos e permitindo apenas dados seguros, protegendo seus dispositivos contra invasões e roubo de dados.
**Terminal Linux:** é uma interface baseada em texto que permite a comunicação direta com o sistema operacional.
**Shell:** é o interpretador que recebe o texto digitado no terminal.
**Bash:** é um interpretador de comandos e linguagem de script padrão em sistemas operacionais baseados em Unix, como Linux e macOS. Ele permite que você interaja diretamente com o
sistema operacional usando textos em vez de uma interface gráfica, sendo excelente para automatizar tarefas repetitivas e gerenciar arquivo.

**Linux != Sistema Operacional**
**Linux = Kernel**
**Sistema Operacional = Ubuntu**
